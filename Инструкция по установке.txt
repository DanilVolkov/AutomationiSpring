1. Скачать архив:
https://github.com/DanilVolkov/AutomationiSpring

2. Установить Python:
https://www.python.org/downloads/

3. Установить UV:
https://docs.astral.sh/uv/getting-started/installation/

Инструкция ниже приведена для Windows.
Для MacOS выполняется всё то же самое, но для файла start.bash.txt.

4. Скопируйте содержимое файла start.bat.txt в буфер обмена.

5. Создайте здесь же новый файл start.bat и откройте с помощью блокнота.

6. Вставьте содержимое из буфера обмена.
   Обратите внимание, чтобы кодировка файла была UTF-8 и разметка CRLF.
   Эти данные можно посмотреть справа снизу.

7. Запустите скрипт start.bat.

8. Заполните созданный файл .env необходимыми данными.

9. Снова запустите скрипт.

10. Перейдите по ссылке из скрипта.
